# Android 图库翻新

普通导入会先清洗，再去重。静态图长边超过 720 像素时按比例缩小，不裁切、不放大。单帧 GIF 当静态图清洗，动态 GIF 保留原文件。导入同一张原图时，重新走同一套处理；静态图除哈希外还核对尺寸和像素，动态 GIF 核对字节。资源包和局域网同步保留既有的协议身份，不重新缩放传入资源。

升级后第一次启动，程序在后台检查旧图，只清洗长边超过 720 像素的静态图。尺寸合格的旧图不重新编码或改名。读取图库和发送无需等待清洗完成。新文件落盘后才更新对应资源及进度；分类、关键词、排序和最近使用仍关联原资源 ID。空间不足时保留本张及后续原图，退出或中断后下次启动从进度继续。成功处理整个旧库后，用版本标记跳过后续的全库扫描。

替换下来的原图留到下一次进程启动，再移入应用私有目录 `files/library-refurbish-v1/original`，已打开的页面在本次运行中仍可访问旧文件。动图、不可清洗和身份冲突的条目保留，不自动合并。已有局域网同步历史的图库保留会改变协议标识的原图，以兼容还没升级的另一端。普通导入优先比对清洗后的内容，原图还在时也可做精确原图去重。
