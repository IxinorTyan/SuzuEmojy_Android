# 文件夹批量导入

分类仍为单层。用户选择的目录决定分类粒度：

- 所选目录直接包含的图片，归入该目录同名分类。
- 每个一级子文件夹对应一个分类；其下所有层级的图片均归入该分类。
- 纯容器目录、空目录，以及没有任何图片成功导入的目录，不创建分类。
- 同名分类复用；确认弹窗展示各分类的候选图片数及新建/合并提示。数量包含尚未解码和去重的候选文件。
- 从指定分类进入导入时，图片同时加入原目标分类，保持已有行为。

例如选择 `Stickers`：

| 来源 | 分类 |
| --- | --- |
| `Stickers/a.png` | `Stickers` |
| `Stickers/猫猫/b.png` | `猫猫` |
| `Stickers/猫猫/动图/搞笑/c.gif` | `猫猫` |
| `Stickers/狗狗/搞笑/d.png` | `狗狗` |

若改为选择 `Stickers/猫猫`，其中直接图片归入 `猫猫`，`动图` 子树的图片归入 `动图`。

系统预留名称 `全部`、`最近`、`ALL`（忽略大小写）不创建分类。文件提供程序未返回目录名时沿用根分类；根目录本身没有可用名称时直接导入资源库。

扫描在后台使用队列遍历，避免深层目录造成递归栈溢出，并跳过已经访问的目录 ID。保留原有图片格式筛选和资源去重机制；同一来源只读取一次，但保留其所有分类关系。一个子目录读取失败时继续其他分支，并在预览和完成摘要中提示扫描不完整及失败路径；根目录无法读取时直接报错。

每张成功导入的图片及时以短事务保存分类关系，取消时先完成当前图片的分类事务。取消或发生数据库错误后不触发原图清理。进程被系统终止不提供自动续传，可重新选择来源进行去重导入并补全分类。

## 验证

`FolderImageScannerTest` 覆盖三级嵌套、重新选择根目录、根目录图片、空目录、MIME/扩展名识别、不可读分支、根目录错误、循环目录、共享来源、2000 层嵌套及取消。

设备回归时，准备上表目录结构，使用系统文件夹选择器选择 `Stickers`，确认分类预览、实际图片归属及同名分类复用。再选择 `猫猫` 验证分类边界变化。另需验证扫描/确认/导入时旋转屏幕、后台返回、取消后重新导入，以及特定文件提供程序的权限错误；JVM 测试不替代这些设备检查。
