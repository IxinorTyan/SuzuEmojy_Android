# GitHub 发行版更新提醒

- 数据源为 `IxinorTyan/SuzuEmojy_Android` 的公开 `GET /repos/{owner}/{repo}/releases/latest` 接口；仅正式发行版，不使用普通标签、提交日期或 APK 文件名推测版本。
- 本机使用 `BuildConfig.VERSION_NAME` 与发行版 `tag_name` 比较。支持 `v1.7.3`、`1.7.10`、`1.8.0-rc.1` 和构建元数据。发布时请使用规范的递增版本号，APK 的 `versionCode` 仍需正常递增。
- 首页创建时自动检查；成功检查后 24 小时内不再自动请求，失败后至少间隔 1 小时。关闭应用时不运行常驻任务；自动检查失败不会弹窗。
- 关于页可关闭自动检查，也可点击版本号立即手动检查。手动检查显示等待状态，并区分当前无新版本、尚无正式发行版、网络错误、限流与版本号无法识别。
- 发现新版后显示版本号及最多 1200 字符发行说明。点击“前往更新”使用系统默认浏览器打开固定仓库地址 `https://github.com/IxinorTyan/SuzuEmojy_Android`；未设置默认浏览器时只展示浏览器选择，不强制跳转 GitHub App。应用不下载、不安装 APK。
- 检查只发送公开 HTTPS 发行版查询及应用版本 User-Agent，不附带表情、数据库、账号令牌或聊天数据。连接和读取均设 8 秒超时，响应限制 1 MiB。
- 检查保存在 ViewModel 中，旋转不会重复请求；仅在页面恢复可交互后显示结果，旋转时恢复未确认的更新弹窗。“稍后”关闭当次提醒，后续自动检查可再次提醒。

## 回归

`UpdateCheckPolicyTest` 覆盖数字版本比较、相同/旧版、预发行顺序、异常标签、大数字、自动检查间隔、失败退避和系统时间回退。

设备验证：关于页手动检查、无网络重试、关闭自动检查、检查时旋转/切后台；模拟比本机更高的正式版验证弹窗；分别在已装 GitHub App、有/无默认浏览器时确认“前往更新”落到浏览器中的仓库首页。JVM 测试不能替代浏览器路由和实际网络设备检查。
